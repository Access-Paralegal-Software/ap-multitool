# Developer Tooling Handoff

## Summary

This tooling lane added small local scripts for developer and operator diagnostics without changing application behavior.

## New Scripts

- `scripts/inspect_telemetry.py`: read-only telemetry inspector for `~/.access_paralegal_telemetry.json`.
- `scripts/run_core_tests.py`: pytest launcher with named subsets for common development checks.

## Usage

Telemetry inspection:

```powershell
python scripts/inspect_telemetry.py
python scripts/inspect_telemetry.py --errors 10
python scripts/inspect_telemetry.py --json
```

Test launcher:

```powershell
python scripts/run_core_tests.py
python scripts/run_core_tests.py --subset unit
python scripts/run_core_tests.py --subset integration
python scripts/run_core_tests.py --subset qt -- -q
```

Detailed usage lives in `docs/ops/dev_tools.md`.

## Logging Review

Reviewed logging and direct diagnostic output in `core/`, `apmultitool_qt/`, `cli.py`, and `email_processing.py`.

No runtime logging cleanup was applied in this lane. The core remains logger-free and Qt-unaware, CLI logging remains centralized in `cli.py`, and legacy direct `print()` usage was documented for a future pass rather than changed here.
