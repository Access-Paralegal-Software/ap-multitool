## Architecture summary

```
convert_docx_to_pdf(src, out, backend=None)   ← new public abstraction
    │
    ├─ backend == WIN32COM:
    │     _convert_via_win32com_word()          ← private, Windows only
    │     if fails AND fallback enabled AND soffice available:
    │         run_soffice_convert()             ← shared utility in _conversion_backend.py
    │         return [warning]
    │     else:
    │         raise RuntimeError
    │
    ├─ backend == LIBREOFFICE:
    │     run_soffice_convert()                 ← non-Windows primary path
    │
    └─ backend == NONE:
          raise RuntimeError

handle(job, progress)                           ← unchanged Job-level entry point
    └─ delegates to convert_docx_to_pdf()
```

## Feature flag

```
APM_MULTITOOL_USE_LIBREOFFICE_FALLBACK   default "1" (enabled)
APM_CONVERSION_BACKEND                   default (auto-detect)
```

Windows users with Office installed are unaffected regardless of flag value,
because the win32com path succeeds before the fallback is ever consulted.
