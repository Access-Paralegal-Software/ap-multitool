Access Paralegal Multitool — FAQ

1. What is APMultitool?

APMultitool is a secure, 100% offline local document suite engineered specifically for legal support professionals. It runs directly on your computer to compile court-ready document packets, harvest email attachments, and apply permanent, flattened Bates stamping without uploading any sensitive client files to third-party cloud servers.

2. Is this release Windows-only?

Yes, the Beta 1 release is Windows-only, supporting 64-bit installations of Windows 10 and 11. macOS and Linux builds are actively in development and will be released in future versions of the software.

3. Why might Windows SmartScreen warn me?

Because APMultitool is a newly compiled release and not yet signed with a commercial certificate, Windows Defender will display a warning dialog ("Windows protected your PC") when running the installer. This is completely normal. Click "More info" and then "Run anyway" to launch the installation wizard.

4. Do I need Microsoft Office installed?

Yes, locally compiling or converting Microsoft Word (.docx) and Excel (.xlsx) files requires a local installation of Microsoft Office on the same machine. Standard PDF merging, image handling, and text file operations do not require Office.

5. How do I request support or submit feedback?

Please send all bug reports, technical logs, feature requests, and general usage feedback via email to info@accessparalegalservices.com.
