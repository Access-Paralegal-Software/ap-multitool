## ⚡ 4. Risks & Open Questions

*   **Offline Cryptographic Vault Breakage**: The case decryption model binds salting to the machine's motherboard UUID. If the local directory name changes or paths mutate without verification, it may lock users out of their secure offline case folders. **DoD Step 3 must be run and tested before formal deployment.**
*   **Keygen License Activation Sync**: We must confirm that the new build executable (`ap_multitool.exe`) maps correctly to the active license portal without breaking keygen account tokens.
*   **Win32com Office Engine Dependency**: DOCX-to-PDF conversion relies on standard MS Office COM local engines via `win32com`. Testing must confirm that MS Office installs remain bound correctly post-renaming.
