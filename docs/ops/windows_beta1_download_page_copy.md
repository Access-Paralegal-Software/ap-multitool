## Subhead

A local-first document workbench for paralegals and legal support professionals. Your files never leave your machine.

---

## What You Can Do

- **Compile documents into a single PDF.** Add PDFs, Word files, and Excel files to a queue, arrange the order, and merge them in one click. Accidentally overwriting an existing file is blocked automatically.
- **Apply Bates numbers to production sets.** Configure the prefix, starting number, and formatting — then stamp an entire PDF in one run. You can cancel mid-job without leaving partial output behind.
- **Build matter folder structures from blueprints.** Select a predefined template, preview the folder tree, and create a complete standardized directory for a new matter in seconds.
- **Work from the command line.** Every core operation is available as a CLI command for scripted workflows or batch processing.
- **Diagnose problems instantly.** If something goes wrong, export a support bundle from the Help & About tab with one click. No case data is included — only logs and environment details.

---

## Before You Install

**System requirements:** Windows 10 or 11 (64-bit)

**This is a beta release.** APMultitool v1.0.0-beta1 is stable for regular use, but you may run into rough edges. We want your feedback — every report helps us get to a clean release.

**Windows security warning (SmartScreen).** The installer is not yet code-signed, so Windows will display a warning when you run it. This is expected. To proceed:

1. Click **"More info"** in the blue warning dialog.
2. Click **"Run anyway"** to launch the installer.

If you prefer to verify the installer before running it, a SHA256 checksum is listed alongside the download file.

**Word and Excel files.** APMultitool can include Word (.docx) and Excel (.xlsx) files in a compiled PDF. This feature requires Microsoft Office to be installed on your machine. Files will be skipped with a clear error message if Office is not available.
