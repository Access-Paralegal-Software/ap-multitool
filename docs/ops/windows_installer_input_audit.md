## 2. Bundling Strategy

The `packaging/windows/prepare_bundle.ps1` script gathers the files into a single distribution folder at `dist/APMultitool_Bundle`.
The files consolidated inside the bundle are:
1. `Access_Paralegal_Multitool.exe` (GUI executable)
2. `apmultitool.exe` (CLI executable)
3. `logo_small.png`
4. `water_texture.png`
5. `LICENSE` (dynamic UTF-8)
6. `README_BUNDLE.txt` (developer/admin instructions)
7. `launch_cli_help.bat` (helper to start CLI shell)
