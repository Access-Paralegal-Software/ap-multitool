## 2. Core Value Propositions

### 🛡️ 100% Local and Privacy-First
All file processing is performed natively on your machine. Your emails, case filings, and sensitive client briefs never cross network lines or upload to external SaaS clouds.

### ⚡ Dual Interfaces: Desktop GUI + Headless CLI
Whether you prefer drag-and-drop workspace compilation or scripting complex document queues via shell, APMultitool packages a beautiful GUI and a developer-ready CLI in a single executable.

### 📐 Automated Collision-Avoidance Bates Numbering
Bates stamp your records confidently. The engine automatically shrinks page contents when margin collisions are detected, maintaining clean, visible page borders.

## 3. Core Feature Highlights
- **Unified Engine**: Merge EML, MSG, DOCX, XLSX, images, and PDFs seamlessly.
- **Grayscale Optimization**: Compress images and emails to high-contrast, black-and-white layouts matching PACER electronic filing directives.
- **Zero Cloud Subscriptions**: One installer, zero licensing fees, zero cloud dependencies.
- **Developer Ready**: Machine-readable `--json` output flags and silent installations (`/SILENT` setups) for enterprise IT group deployments.
