# ap-multitool / scripts

Utility and migration scripts for the Access Paralegal multi-tool suite.

## Script inventory

| Script | Purpose |
|--------|---------|
| `eml_to_pdf.py` | Converts .eml email files to PDF |
| `generate_apmultitool_pdf.py` | Generates AP Multitool documentation PDF |
| `thunderbird_inject.py` | Injects email data into Thunderbird profile |
| `aps_imap_migrate.py` | IMAP migration tool for APS mailboxes |
| `_aps_delta_sync.py` | Delta sync for APS mail data |
| `_check_aps_dns.py` | DNS health check for accessparalegalservices.com |
| `_cutover_aps_dns.py` | Executes DNS cutover for APS domains |
| `_lower_aps_ttl.py` | Lowers DNS TTL before cutover |
| `_provision_aps.py` | Provisions APS mailboxes on stax-mail-01 |
| `_regen_mobileconfig.py` | Regenerates Apple mobileconfig for APS accounts |
| `renee-aps.mobileconfig` | Apple mobileconfig for Renee APS account |
| `APMultitool_Beta1_Overview.pdf` | Beta 1 product overview document |
