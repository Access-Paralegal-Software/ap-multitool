# Title-Toolkit

Metes-and-bounds deed parser and Bowditch closure calculator for AP-Suite.

## Features
- **Metes-and-Bounds Deed Parser**: Extracts survey calls, quadrant bearings (e.g. `N 45° 30' 00" E`), horizontal distances, and point of beginning (POB).
- **Bowditch Closure Calculator**: Implements the Compass Rule (Bowditch traverse adjustment) to compute:
  - Latitudes and departures per leg
  - Linear error of misclosure
  - Closure precision ratio (e.g., 1:15,000)
  - Adjusted coordinate pairs
