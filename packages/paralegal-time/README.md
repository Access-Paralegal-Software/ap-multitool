# Paralegal-Time

Multi-firm timer rules and LEDES 1998B formatters for AP-Suite.

## Features
- **Multi-Firm Timer Rules**: Configurable billing increments (e.g. 6-minute tenths, 15-minute quarters), rounding modes (up, nearest, down), and minimum billable times.
- **LEDES 1998B Formatters**: Compliant UTBMS and LEDES 1998B generation for invoice export and billing system synchronization.
