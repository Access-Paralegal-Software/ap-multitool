# Trial-Deck

Dual-monitor courtroom presentation bus for AP-Suite.

## Features
- **Presentation Bus**: Decoupled state management between Counsel's control deck and the Jury/Witness monitor.
- **Safety Blackout / Whiteout**: Instant curtain/blackout trigger to hide exhibits during sidebar arguments or judicial conferences.
- **Dynamic Callout Sync**: Coordinates synchronized callout zoom boxes across screens in real-time.
