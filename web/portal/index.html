⚠️ Before You Install

System Requirements: Windows 10 or 11 (64-bit). Please note that compiling Word (.docx) and Excel (.xlsx) files requires Microsoft Office to be installed locally on your machine.

🛡️ Windows Defender SmartScreen Warnings

Since APMultitool is a newly compiled release and not yet signed with a commercial certificate, Windows Defender will display a warning dialog ("Windows protected your PC") when running the installer. This is normal. To proceed:

  1. Click "More info" inside the blue warning dialog.
  2. Click "Run anyway" to launch the installation wizard.

👥 Who this Beta is for

This early access build is intended for trusted testers and early adopters who are comfortable evaluating pre-release software. It is not yet meant for a general-purpose, fully polished release.

📬 How to report beta issues

If you run into bugs, crashes, installation problems, or confusing behavior in this beta, please email a short description to info@accessparalegalservices.com.

Useful Feedback Includes: Installation problems, SmartScreen issues, confusing workflows, UI problems, performance issues, or incorrect data.

Short checklist of what to include:
  • What you were trying to do.
  • What happened instead (and any error messages).
  • Which version of Windows you are using.
  • A screenshot of the issue (if applicable).
  • An offline Support Bundle (details below).
🛠️ Generating offline Support Bundles

If you encounter bugs, go to the Help & About view inside APMultitool and click "Export Support Bundle". This generates a ZIP file on your desktop with application logs and environment details. No document contents or client files are included.
